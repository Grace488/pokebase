# Pokémon Pokedex Web App

Sebuah aplikasi web interaktif untuk menampilkan kartu Pokémon dengan desain modern ala trading card, dibuat dengan React, Tailwind CSS, dan Framer Motion. Data diambil secara realtime dari PokéAPI.

## Fitur Utama
- Tampilan kartu dengan efek holografik dan animasi 3D tilt.
- Mode terang/gelap (Dark/Light mode).
- Pencarian Pokémon dan filter berdasarkan tipe.
- Pengurutan berdasarkan Nomor, Nama, dan HP.
- Detail modal dengan suara/cry Pokémon dan toggle bentuk Shiny.
- Sistem favorit (disimpan di `localStorage`).
- Responsif untuk semua ukuran layar.

## Persyaratan
- Node.js (versi 18+ disarankan)
- NPM

## Cara Menjalankan

1. Instal dependensi:
   ```bash
   npm install
   ```

2. Jalankan development server:
   ```bash
   npm run dev
   ```

3. Buka URL yang tertera di terminal (biasanya `http://localhost:5173/`) pada browser Anda.
